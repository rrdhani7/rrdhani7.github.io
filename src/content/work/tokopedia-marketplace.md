## Konteks

Saya bergabung di Tokopedia sekitar 2017 sampai 2018, saat Tokopedia sedang membangun campaign flash sale untuk pertama kalinya. Saya tergabung dalam project reliability system untuk campaign tersebut.

## Project reliability system

Tugas saya melakukan load testing untuk memastikan sistem, khususnya fitur checkout, mampu menangani jutaan traffic selama flash sale berjalan. Project ini berjalan dengan baik, dan flash sale pada Ramadan juga berjalan dengan baik. Sampai sekarang, Tokopedia mampu menangani jutaan traffic dengan seamless.
