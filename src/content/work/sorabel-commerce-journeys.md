## Konteks

Di Sorabel, saya pertama kali bekerja sebagai full-stack QA. Saya menjadi satu-satunya QA di tim, jadi seluruh proses QA ada di tangan saya.

## Dari QA fundamental sampai CI/CD

Saya belajar mulai dari QA fundamental seperti black box testing dan manual testing, lalu membuat dan merawat automation test, sampai merawatnya di pipeline CI/CD. Dengan begitu saya menjalankan proses QA end to end sendiri, dari memahami kebutuhan sampai memastikan test berjalan otomatis di pipeline.
